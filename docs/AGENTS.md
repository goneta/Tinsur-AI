# DOX framework

## Purpose

- Owns durable onboarding and project documentation.

## Ownership

- Onboarding docs for admins, clients, and insurance companies live here.
- Root-level reports and milestone documents remain parent-owned unless moved here as durable docs.

## Local Contracts

- Keep docs concise, current, and operational.
- Prefer stable workflow and product guidance over historical status notes.

## Work Guidance

- Update docs when user-facing workflows, roles, or onboarding requirements change.
- Remove stale or contradictory instructions instead of appending corrections.
